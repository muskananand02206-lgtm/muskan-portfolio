# Muskan Anand — Personal Portfolio

A responsive, typography-led portfolio website built with HTML, CSS and a small amount of JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — visual design, layout, responsive styles and CSS demonstrations
- `script.js` — mobile navigation and dynamic footer year

## Preview locally
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.
3. Internet access is needed to load the Google Fonts; the site falls back to system fonts if unavailable.

## Publish with GitHub Pages
1. Create a GitHub account and a new **public** repository (for example, `muskan-portfolio`).
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Copy the live URL and repository URL into the assignment PDF.
